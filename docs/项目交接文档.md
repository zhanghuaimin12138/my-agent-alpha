## 一、这是什么项目

仿照 [gptme](https://github.com/ErikBjare/gptme) 做的**个人 AI agent**,定位是学习型重实现:不照抄代码,而是按蓝图自己写一遍,把每个设计决策记进开发日志。纯 Python 命令行程序,没有图形界面(带界面的版本在暂存分支,见 §5)。

跑起来(在仓库根目录):

```bash
uv run my-agent-alpha                 # 交互模式
uv run my-agent-alpha -m glm/glm-5.3  # 指定模型
```

模型、工具通道等配置的取值顺序:命令行参数 > 环境变量(`ALPHA_MODEL` 等)> 项目配置(`alpha.toml`)> 用户配置(`~/.config/my_agent_alpha/config.toml`)。

## 二、总体架构(一分钟版)

整个程序就是**三层循环**套在一起(这是 gptme 的脊柱,也是本项目最重要的结构):

| 层 | 函数 | 干什么 |
|---|---|---|
| 外层 | `_run_chat_loop()` | 不断取用户输入,相当于普通聊天程序的主循环 |
| 中层 | `_process_message_conversation()` | 处理一条用户输入,反复"生成 → 执行工具"直到模型不再要工具 |
| 内层 | `step()` | 问一次模型 + 把模型这次要的工具跑一遍 |

中层什么时候停?**只看一件事**:日志里最后一条模型回复里还有没有写完整的工具调用。没有额外状态,这是刻意保持的架构纪律。

贯穿全局的几条铁律(全项目都依赖,改动前必读 AGENTS.md"架构纪律"一节):

- **消息是唯一的数据单元**:只有 system / user / assistant 三种角色;工具调用写在 assistant 的文本里;工具输出是带 `call_id` 的 system 消息,和调用一一对应。
- **主日志永不改写**:`conversation.jsonl` 只追加;压缩上下文时"现算视图",不落盘、不动原文件。
- **横切功能全走钩子**:确认、压缩、命名、待办门控……都没改过核心循环一行代码。

## 三、模块清单(按目录)

### 1. 核心(`src/my_agent_alpha/` 根目录)

| 文件 | 完成的功能 |
|---|---|
| [message.py](../src/my_agent_alpha/message.py) | `Message` 消息类:三种角色、不可变(改 = 造新的)、读旧日志时宽容丢弃未知字段 |
| [chat.py](../src/my_agent_alpha/chat.py) | 三层循环本体、终端交互、`MAX_STEPS` 步数上限、流式打印 |
| [logmanager/manager.py](../src/my_agent_alpha/logmanager/manager.py) | 会话日志:`Log`(追加游标,平时只追加不重写)+ `LogManager`(会话目录门面);崩溃安全(临时文件 → 原子改名);最后一行写坏时跳过并告警 |
| [codeblock.py](../src/my_agent_alpha/codeblock.py) | 从模型回复文本里解析 markdown 围栏代码块,即"工具调用"(通道一) |
| [context.py](../src/my_agent_alpha/context.py) | 用 ContextVar 存"当前工作区/会话目录",工具执行时自己取,不用层层传参 |
| [dirs.py](../src/my_agent_alpha/dirs.py) | 按 Linux XDG 惯例算数据/日志/配置路径 |
| [config.py](../src/my_agent_alpha/config.py) | 分层配置(用户 → 项目 → 环境变量,层层覆盖) |
| [prompts/\_\_init\_\_.py](../src/my_agent_alpha/prompts/__init__.py) | 系统提示词组装:静态部分(身份+工具用法)放前可被服务商缓存,动态部分(当前时间)放尾不弄脏缓存 |

### 2. 模型接入(`llm/`)

| 文件 | 完成的功能 |
|---|---|
| [\_\_init\_\_.py](../src/my_agent_alpha/llm/__init__.py) | 门面:外部只调 `reply()`,不关心用的哪家模型;`_StreamWithMetadata` 让"提前停止生成"后也拿得到用量 |
| [models.py](../src/my_agent_alpha/llm/models.py) | 模型名解析:`deepseek/deepseek-chat` = 服务商 + 模型名 |
| [openai_compat.py](../src/my_agent_alpha/llm/openai_compat.py) | 真实服务商客户端:openai / deepseek / moonshot / 智谱 GLM 等接口相同的都走这一个模块;思考过程(reasoning)实时包进 `<think>` 标签;临时性错误自动重试、密钥错误立即报 |
| [mock.py](../src/my_agent_alpha/llm/mock.py) | 假模型:不联网不花钱,测试主力(可预先塞一串脚本式回复) |
| [errors.py](../src/my_agent_alpha/llm/errors.py) | `ContextLengthError`(历史超长被接口拒)单独分类,调用方捕获后可以压缩重试 |

### 3. 工具(`tools/`)

模型调用工具有**两种通道**:markdown 围栏代码块(阶段 1 起)和原生 function calling(阶段 3 起),由 [base.py](../src/my_agent_alpha/tools/base.py) 的 `ToolSpec`/`ToolUse` 统一抽象。[tools/\_\_init\_\_.py](../src/my_agent_alpha/tools/__init__.py) 是注册表 + 白名单(`--tools read,grep` 限制可用工具,subagent 用)+ 批量执行入口。

| 文件 | 工具 | 完成的功能 |
|---|---|---|
| [shell.py](../src/my_agent_alpha/tools/shell.py) | `shell` | 在工作区执行 bash 命令;超时 + 输出截断 + 全量存盘 |
| [shell_safety.py](../src/my_agent_alpha/tools/shell_safety.py) | (配套) | 命令安全三级分诊:只读放行 / 灾难拒绝 / 其余问用户;判不准一律往下走 |
| [read.py](../src/my_agent_alpha/tools/read.py) | `read` | 读文件(带行号),可一次多个 |
| [save.py](../src/my_agent_alpha/tools/save.py) | `save` / `append` | 写文件 / 追加 |
| [edit.py](../src/my_agent_alpha/tools/edit.py) | `edit` | 精确改一小段("旧文本 ===== 新文本"),agent 安全改代码的前提 |
| [grep.py](../src/my_agent_alpha/tools/grep.py) | `grep` | 内容搜索,输出 `路径:行号:命中行`;纯 Python 实现,免确认、忽略垃圾目录 |
| [todo.py](../src/my_agent_alpha/tools/todo.py) | `todo` | 内存任务清单 + **完成门控**:回合结束还有未完成项时自动把模型拉回来,连催几轮不动就熔断 |
| [memory.py](../src/my_agent_alpha/tools/memory.py) | `memory` | 让模型"记一条",经用户确认才写入长期记忆 |
| [subagent.py](../src/my_agent_alpha/tools/subagent.py) | `subagent` | 派子进程干独立活:提示词走 stdin、结果从子会话日志取最后一条模型回复、默认继承父模型、可用 `--tools` 限权 |

### 4. 横切机制(根目录 + `hooks/` + `commands/`)

| 文件 | 完成的功能 |
|---|---|
| [confirm.py](../src/my_agent_alpha/confirm.py) | **确认链**:按优先级排序的钩子链,每个钩子对一次工具调用给"放行/拒绝/改写/不管"之一;链走完没人管就自动放行(脚本、测试、`-y` 走这里) |
| [hooks/\_\_init\_\_.py](../src/my_agent_alpha/hooks/__init__.py) | 通用钩子系统:钩子是生成器,产出消息自动进日志/进模型上下文;生命周期点有 `session.start` / `turn.post` / `loop.continue` 等 |
| [hooks/builtin.py](../src/my_agent_alpha/hooks/builtin.py) | 内置钩子(演示"不改核心循环加功能") |
| [hooks/naming.py](../src/my_agent_alpha/hooks/naming.py) | **会话自动命名**:第一回合结束后让模型起 ≤20 字标题写进 `meta.json`(目录名不动);命名请求不进对话日志,失败不影响会话;`ALPHA_AUTO_NAME=0` 可关 |
| [commands/](../src/my_agent_alpha/commands/) | 斜杠命令框架(`@command` 装饰器注册)+ 内置:`/help` `/exit` `/tools` `/log` `/model` `/hooks` `/memory`(含 `/memory consolidate` 记忆整理) |
| [compaction.py](../src/my_agent_alpha/compaction.py) | **上下文压缩**:规则式三阶段(剥旧思考 → 收敛旧工具输出 → 再不够就旧轮次只留骨架);每次请求现算,不改盘上任何东西 |
| [mcp_client.py](../src/my_agent_alpha/mcp_client.py) | **MCP 客户端**:连外部 MCP 服务器,远端工具转成本地一等 `ToolSpec`(命名 `服务器名.工具名`),于是确认链、提示词、两种通道自动适用;异步 SDK 的坑用专属事件循环线程解 |
| [memory_store.py](../src/my_agent_alpha/memory_store.py) | **长期记忆存储**:一条记忆一个 markdown 文件(frontmatter:name/description/type/created);四类封闭类型(user/feedback/project/reference);两层目录(项目层盖住用户层);description 是"向量的替代品",检索靠模型看描述;读路径有预算上限和新鲜度标注 |

## 七、接手须知(硬规则摘要,全文见 AGENTS.md)

1. **每次开发会话结束前写 devlog**(中文,`docs/devlog/NNN-日期-标题.md`)并更新索引;
2. 永不 `git add .`,显式列文件;未经用户明确要求不 commit、不 push;
3. 代码要过三关才算完:`uv run pytest` 全绿、`uv run ruff check` 零告警、`uv run mypy src`(strict)零错误;
4. 每个函数至少一行**大白话中文注释**(读者是正在学习的人,禁术语黑话;用户自己写的学习注释一律保留);
5. 测试失败就如实展示输出,禁止粉饰。
