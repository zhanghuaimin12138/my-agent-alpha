# 038 · todo 工具与钩子分家(2026-10-30)

## 目标

tools/todo.py 里"工具本体"和"两个钩子"挤在一个文件(394 行),
照 037 的思路继续分家:工具归工具,钩子归 hooks 包。

## 决策及理由

**放哪**:新建 `hooks/todo.py` 放门控(loop.continue)与重放(session.start)
两个钩子 —— 沿用 hooks/naming.py 的既有模式:功能专属的钩子实现
放 hooks 包,hooks/builtin.py 只做注册汇总。清单状态(增删改查)留在
tools/todo.py,钩子只读写它;顺带砍掉了 tools → hooks 的导入边
(tools/todo.py 不再 import hooks)。

**跨模块用的名字去下划线变公开**(037 同款约定):
`_reset_todos`→`reset_todos`、`_parse_and_apply`→`parse_and_apply`、
`_command_text`→`command_text`。另抽两个小公共函数给门控消息用:
`format_item`(一行待办的渲染,read 输出与门控消息共用)、
`incomplete_items`(未完成项排好序,`has_incomplete_todos` 也改用它)。

**状态归属**:清单状态(_todos/_next_id)归 tools/todo.py,门控计数
(_gate_warnings)归 hooks/todo.py —— 各自的 reset 各自管
(reset_todos / reset_gate_warnings),conftest 两个都调。

## 改动结构

```
tools/todo.py   394 → 262 行:清单状态 + 子命令文法 + ToolSpec(纯工具)
+ hooks/todo.py 148 行:GATE_PREFIX、MAX_GATE_WARNINGS、门控计数、
                todo_gate_hook、replay_todo_hook、register_todo_hooks
hooks/builtin.py   注册导入路径 tools.todo → hooks.todo
tests/conftest.py  重置改为两笔:todo_mod.reset_todos() + reset_gate_warnings()
tests/test_todo_gate.py  门控相关导入改指 hooks.todo;execute_todo 用 todo_tool 别名
```

逻辑一行没改,只有 has_incomplete_todos 从手写 any(...) 改为
`bool(incomplete_items())`(等价)。
