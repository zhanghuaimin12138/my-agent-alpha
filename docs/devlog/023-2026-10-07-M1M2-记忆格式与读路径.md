# 023 — M1+M2:记忆格式地基与读路径(frontmatter、类型学、双上限、新鲜度)

## 目标

实施《长期记忆改进方案》的 M1(格式与提示词地基)+ M2(读路径:预算与新鲜度)。
这是对照 Claude Code 记忆架构报告的第一期改造,零依赖新机制,全部落在
memory_store.py / tools/memory.py 两个文件里。

## 决策及理由

1. **content 可以自带 frontmatter(比方案多想了一步)**:方案只说工具加
   type/description 参数,但 markdown 围栏通道没有参数位——描述写不进去,
   索引质量就回到老样子。让 content 开头允许一段 frontmatter(description/type),
   显式参数 > 内容 frontmatter > 默认值,两条通道就对称了,而且复用同一个
   `_parse_frontmatter` 解析器。这也更接近 CC 的哲学:模型就是在"写文件"。
2. **链接文本用名字(stem)不用标题**:索引行的链接文本是模型执行
   "同名覆盖更新"的钥匙(update-before-create 要拿名字),标题信息由
   description 承载,不重复。
3. **注入索引从文件现算,不读 MEMORY.md**:新鲜度(mtime)和同名盖层
   只有扫文件才知道;MEMORY.md 降级为纯给人看的镜像,在每次 save 时重建。
   副产品:手写放进 memory/ 的文件立即对模型可见(旧行为要等下次 save
   触发重建才进索引),`_with_real_paths` 的正则改写 hack 也随之删除。
4. **双上限按层卡(100 行 / 16KB)**:我们两层目录各一份,单层配额取
   CC(200 行/25KB)的一半,总量相当;先按行截再按字节截,截断注明
   触发了哪个上限(CC §2.6 的教训:单上限挡不住另一种超限)。
5. **读时兼容,写时升级**:旧格式文件解析时回填默认值(类型 project、
   描述=标题),文件本体一个字不动;只有再次经过 save_memory 才落成新格式。
   不做一次性迁移脚本。
6. **未知类型防御性回落 project,工具层前置校验**:store 层不让脏数据
   进索引,工具层对非法 type 给出可读报错且不落盘。

## 改动结构

- `src/my_agent_alpha/memory_store.py`(重写大半):
  - 新增 `MEMORY_TYPES` 四类类型学、`_parse_frontmatter` / `_parse_memory_text`
    解析器(新旧格式通吃)、`_age_label`(mtime → "今天/N 天前/⚠旧")、
    `_cap_lines`(行数+字节双截断);
  - `MemoryEntry` 加 `description` / `mem_type` 字段;
  - `save_memory` 加 `mem_type` / `description` 参数,落盘统一新格式;
  - `rebuild_index` 行格式升级为 `- [名](文件) — 描述(类型)`;
  - `render_memory_index` 改为从文件现算,行尾带 `类型·年龄`,头部带
    "引用前先验证"行为协议;删除 `_with_real_paths` 和旧 64KB 单预算。
- `src/my_agent_alpha/tools/memory.py`:加 `type` / `description` 参数
  (原生通道),围栏头支持 `​```memory 名 类型`;`_PROTOCOL` 提示词协议
  (四类何时保存、排除清单、从成功中学习、相对日期转绝对、update-before-create)

- `tests/test_phase8.py`:新增 7 个用例(往返、旧格式兼容、内容 frontmatter、

## 已知限制

1. **markdown 通道的 description 质量取决于模型**:协议教它把 frontmatter
   写进内容开头,但 kimi 等围栏服从率低的模型可能不写——此时回填标题,
   索引退化但可用。真机实测留到日常使用观察。
2. **双上限数值(100 行/16KB)和 30 天阈值是估计值**,方案风险节已注明
   待真实记忆量校准。
3. **MEMORY.md 镜像与注入视图在"手写文件"场景短暂分叉**(镜像只在 save 时
   重建):注入视图是全的,镜像缺手写条目——无功能影响,下次 save 自愈。
4. 原生通道 desc+instructions 拼接截断在 1000 字符:当前协议约 400 字,
   余量充足,但将来扩协议要留意。
