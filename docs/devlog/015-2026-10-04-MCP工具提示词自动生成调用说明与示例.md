# 015 · MCP 工具提示词:自动生成调用说明与示例

## 目标

修复踩坑记录条目 3:真实会话里模型连续猜错 MCP 工具的 markdown 调用格式
(裸文本 → 错;`{"q": ...}` 键名错,正确是 `query`),每错一次浪费一整轮
交互 + 一次用户确认。

## 决策及理由

根因是**约定没有传达给模型**:`_make_spec` 生成的 ToolSpec 只带远端
description,`instructions`/`examples` 全空;而 markdown 通道下参数表
(parameters)也不进提示词(只有原生通道转 JSON Schema 时用)——模型既不知道
"围栏内容要写 JSON 参数体",也看不到参数名,只能按语义瞎猜。

修法:按参数表**自动生成**说明书,而不是靠远端描述碰运气:

- `instructions`:格式约定 + 参数清单(名字/类型/必填/描述);
- `examples`:必填参数生成可照抄的示例围栏,占位值按类型挑
  (string → `<参数名>`,number → 1,boolean → true)。

这样远端服务器描述写得再简陋,本地说明书也完整。

## 改动结构

| 文件 | 改动 |
|---|---|

## t.slow

markdown 通道调用:围栏内容写 JSON 参数体(键名必须用下面的参数名):
- seconds(number,必填)

```

## 已知限制

- 参数描述来自远端 schema,质量取决于服务器(没有也不影响格式教学);
- 示例只放必填参数,选填参数靠参数清单自己组合。
