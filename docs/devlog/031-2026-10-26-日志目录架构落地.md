# 031 日志目录架构落地(实施 030 方案)

- 日期:2026-10-26
- 性质:实施 [030](030-2026-10-25-日志目录架构重构方案.md) 方案——代码落地 + 三关全绿 + 真机验收 + 记忆搬迁
- 拍板结果:指纹维持 **8 位**;拍板 **A**(配置目录改连字符)与 **B**(/log list 显示改造)均按推荐执行

## 一、目标

把会话目录从 `~/.local/share/my_agent_alpha/logs/<日期-随机码>/` 迁到
`~/.local/share/my-agent-alpha/projects/<工作区键>/logs/<uuid4>/`,
会话目录内部(conversation.jsonl / meta.json / tool-outputs)一项不变。

## 二、本次实施中新产生的决策

| 决策 | 理由 |
|---|---|
| `/log list` 循环里用 `shown` 而不是 `title` 作变量名 | 同函数下方"当前会话"分支给 `title` 赋 `str \| None`,先出现的 `str` 推断会让 mypy 抗议 |
| 真机验收用的 mock 会话,验完即删 | 它们是假会话(标题是 mock 回声),留着会污染 /log list;数据目录保持干净 |
| 030 验收第 5 条(subagent)用离线测试代替真机 LLM | `test_subagent_tool_spawns_and_returns` 起的是**真子进程**(python -m my_agent_alpha),只是模型用 mock;链路真实性足够,不烧真模型 |

## 三、改动结构

| 文件 | 改动 |
|---|---|
| `src/my_agent_alpha/dirs.py` | 重写:新增 `workspace_key()`(归一→编码→指纹)与 `get_session_root()`;删除 `get_logs_dir()`;数据/配置目录名改连字符(`_APP_DIR = "my-agent-alpha"`) |
| `src/my_agent_alpha/logmanager/manager.py` | `generate_conversation_id()` 改返回 `uuid4().hex`(注释写明"为什么不含日期");`secrets`→`uuid` 导入 |
| `src/my_agent_alpha/__init__.py` | `main()` 两行:`get_session_root(args.workspace)` 替代 `get_logs_dir()`;`--name` 流程不动(subagent 契约) |
| `src/my_agent_alpha/tools/subagent.py` | 两处 `get_logs_dir()` → `get_session_root(get_workspace())` |
| `src/my_agent_alpha/commands/builtin.py` | `/log list` 重写:按修改时间倒序,显示 `时间 + 标题 + (uuid前8位)` |
| `tests/test_dirs.py` | 新建 4 用例:同目录不同写法(尾斜杠/`..`/软链)同键;孪生命名分键;默认布局;`ALPHA_LOGS_HOME` 覆盖 |
| `tests/test_logmanager.py` | 会话 id 格式断言改为 32 位十六进制 |
| `tests/test_naming.py` | /log list 断言适配新显示(只含 uuid 前 8 位) |
| `tests/test_phase8.py` | subagent 子会话目录改从 `get_session_root()` 找 |
| `tests/test_commands.py` | 新增 /log list 排序/显示用例(用 `os.utime` 伪造新旧) |
