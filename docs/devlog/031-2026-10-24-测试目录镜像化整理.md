# 031 · 测试目录镜像化整理

## 目标

按新定的规则重组 `tests/`:单元测试目录树与 `src/my_agent_alpha/` 一一镜像,
集成测试单独放 `tests/integration/`。规则先写进 AGENTS.md,再把原有的
34 个平铺测试文件全部归位。

## 决策及理由

1. **单元/集成的判定标准看"测的是什么",不看用什么驱动**:
   目标是"一个模块的函数/类" → 单元;目标是"多个模块装配后的行为"
   (完整 chat() 循环、真实子进程、MCP 连接)→ 集成。用 mock provider
   不影响归属——否则几乎全部测试都会被误判成"集成"。
2. **测包门面时文件用包名**:工具注册表行为由 `tools/__init__.py` 导出,
   测试叫 `tests/unit/tools/test_tools.py`(不叫 test_init.py),
   和 gptme 及常见实践一致。
3. **集成测试按场景命名**,不镜像源码树(它本来就不对应单个文件)。
4. **pytest 配 `--import-mode=importlib`**:允许两棵树出现同名文件
   (`unit/hooks/test_hooks.py` 与 `integration/test_hooks.py`),
   按路径区分模块,不需要给测试目录加 `__init__.py`。
5. **混合文件拆开而非整体归位**:12 个文件既是单元又是端到端
   (test_confirm/test_phase8/test_streaming 等),拆开才能让镜像规则成立;
   每个测试的注释(审查编号、真机实录出处)原样随测试搬家,历史不丢。
6. **删 8 个语义重复的用例**(见验证结果),整理的题中之义;
   其余 367 个测试一一对应原有用例,无新增无改写断言。

## 改动结构

- `AGENTS.md`:新增"测试目录规则"一节(6 条),更新"加一个模块"任务指引。
- `pyproject.toml`:pytest 加 `--import-mode=importlib`。
- `src/my_agent_alpha/context.py`:新增 `clear_current_model()`;
  `tests/conftest.py` 的 autouse 夹具调用它。原夹具自称清理 ContextVar
  却漏了模型变量——旧布局里 `test_autocompact_adapters.py` 按字母序
  排第一,恰好一直没人先设过模型,换个目录顺序就把这个缺口暴露了。
- `src/my_agent_alpha/codeblock.py`:仅去掉用户学习注释里的两处行尾空格
  (ruff W291),内容一字未动。
- `tests/` 重组(全部 git mv 保留历史,混合文件拆分):
  - `tests/unit/` 镜像 `src/my_agent_alpha/`:根模块 7 个文件
    (chat/codeblock/compaction/config/confirm/memory_store/message)、
    autocompact/ 8 个、commands/ 1 个、hooks/ 2 个、llm/ 4 个
    (llm/mock/models/openai_compat)、logmanager/ 1 个、prompts/ 1 个、
    tools/ 10 个(base/edit/grep/memory/read/save/shell/shell_safety/todo/tools);
  - `tests/integration/` 按场景 13 个文件 + `mcp_echo_server.py` 随迁;
  - `clean_dirs` 夹具从 test_phase8.py 提升到 `tests/conftest.py`。

## 验证结果

- 整理前:`uv run pytest --collect-only -q` → **375 collected**;整理后 → **367 passed**
  (`367 passed in 10.65s`),`uv run ruff check .` → All checks passed,
  `uv run mypy src`(strict)→ no issues in 48 source files。
- 数差 8 = 删除的语义重复用例,清单(左边删、右边留等价用例):
  1. test_chat::test_exit_command ≈ test_commands::test_e2e_exit_command_via_chat(后者注明"更新自旧版")
  2. test_chat::test_unknown_slash_treated_as_text ≈ test_commands::test_e2e_unknown_command_treated_as_text
  3. test_native_tools::test_native_unclosed_json_skipped ≈ test_iter_from_content::test_native_unclosed_json_ignored
  4. test_native_tools::test_native_call_line_parsed ≈ test_iter_from_content::test_native_basic_call
  5. test_native_tools::test_native_inside_fence_is_example_not_call ≈ test_iter_from_content::test_native_inside_fence_is_example
  6. test_tools::test_unknown_langtag_ignored ≈ test_iter_from_content::test_md_unknown_lang_ignored
  7. test_tools::test_unterminated_fence_not_executed ≈ test_iter_from_content::test_md_unterminated_fence_dropped
  8. test_tools::test_native_call_inside_think_ignored ≈ test_iter_from_content::test_think_native_not_a_call
- 顺序敏感问题的回归验证:全量跑通过(此前 test_adapters 的模型泄漏已由
  clear_current_model 修复,单独跑/全量跑均绿)。
