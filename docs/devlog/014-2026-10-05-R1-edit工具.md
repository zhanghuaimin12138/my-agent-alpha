## 设计

对照 Claude Code 的 Edit 和 gptme 的 patch:

- markdown 围栏内容 = 旧文本 + 一行 `=====` 分隔 + 新文本;
- 原生通道 = `{"path", "old", "new"}` 三个参数;
- 旧文本必须**恰好出现一次**(多次 → 报错教模型带上更多上下文;
  零次 → difflib 找最相似位置,报行号和相似度,教模型先 read 再原样复制);
- 原子写(临时文件 → os.replace),不留垃圾文件。
