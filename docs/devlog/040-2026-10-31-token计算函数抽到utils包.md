# 040 —— token 计算函数抽到 utils 包

## 目标

把 compaction.py 里的三个"纯 token 计算"函数抽到新建的 `utils/` 包,
让 compaction 只管"怎么压"(压缩策略),token 的"数多少"归 utils。

## 决策及理由

- **抽哪三个**:`estimate_tokens`(估算一段文字的 token 数)、
  `messages_tokens`(一批消息求和)、`get_context_budget`(历史最多能占多少 token)。
  前两个是用户点名要的;第三个虽然住在 compaction 里,但它也是纯 token 算术,
  而且 chat.py 在用它(紧急半预算),一起搬走后 chat.py 不再从 compaction 拿它,
  依赖方向更清楚:utils(纯函数)← compaction(策略)/ chat(编排)。
- **不留旧导入别名**:本仓库自己的代码,所有引用点一次性改掉,不做 `compaction.estimate_tokens`
  这种向后兼容的转出口 —— 少一层间接,找实现时不会被中转站骗到。
- **导出走包 `__init__`**:和 AGENTS.md 常用任务的约定一致,外部统一
  `from my_agent_alpha.utils import ...`。

## 改动结构

- 新增 `src/my_agent_alpha/utils/__init__.py`(重导出三个函数)。
- 新增 `src/my_agent_alpha/utils/tokens.py`(三个函数原样搬入,注释原样保留)。
- `src/my_agent_alpha/compaction.py`:删除三个函数,改为 `from my_agent_alpha.utils import ...`;
  其余压缩逻辑(三阶段、兜底、prepare_messages)不动。
- `src/my_agent_alpha/chat.py`:`get_context_budget` 改从 utils 导入。
- `tests/test_compaction.py`:三个函数的导入改从 utils。
- 顺手修了 `tools/__init__.py` 里三处 ruff 告警(行尾空白、空行空白、
  一条超长注释折成两行 —— 注释文字一字未动,只是换行)。
