## 一、现象(真机实录)

用户输入"测试log,返回ok即可",自动命名钩子把标题写成了:

```
(会话已命名:<think>The user wants a title )
```

原因:命名回复把思考原文写在开头(该模型未走独立思考通道),
而 `_clean_title` 直接"取首行"——首行是 `<think>`,标题就污染了。
且这个案例的思考区**没闭合**(流里只写到一半),`<think>` 后面全是推理、没有真标题。

## 二、修法

`_clean_title` 先过现有的 `strip_think()`([codeblock.py:39](../../src/my_agent_alpha/codeblock.py),
连 `<thinking>` 变体都认),再取首行、剥引号、限长:

- 闭合思考区:`<think>推理…</think>真标题` → 剥掉,得真标题;
- 未闭合思考区:`strip_think` 按其既定策略返回空串("宁可全不解析")
  → `_clean_title` 返回空 → 钩子不写标题,下回合重试(既有重试机制,零新代码)。

为什么不另写正则:013 号 devlog 踩坑后项目里已有经过实战的剥思考实现,复用即可。
